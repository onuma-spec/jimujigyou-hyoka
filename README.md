# 住民による事務事業優先度評価ツール

各自治体が公表している事務事業評価データをもとに、住民が個々の事業を「続行・廃止・見直し」の3段階で評価し、共有できる無料ツールです。

## 公開URL
https://onuma-spec.github.io/jimujigyou-hyoka/

## 構成
- `index.html` — ハブページ。都道府県→市区町村の2段階ドロップダウンで自治体を選び、各評価ツールへ移動します
- `about.html` — ツールの解説ページ
- `{自治体名}_index.html` — 各自治体版の評価ツール本体（単一HTML）
  - 西宮市・北本市・湖西市・品川区・富田林市・聖籠町・一宮市

## 仕組み
1. フィルター画面で担当部・法的根拠・行政評価方針・評価結果などで絞り込み
2. カード画面で1事業ずつ「続行／廃止／見直し」を評価
3. サマリー画面で評価結果の一覧を確認・共有

評価結果はブラウザのlocalStorageに保存され、サーバー等外部には送信されません。
