# 住民による事務事業優先度評価ツール

各自治体が公表している事務事業評価データをもとに、住民が個々の事業を「続行・廃止・見直し」の3段階で評価し、共有できる無料ツールです。

## なぜ作ったか

多くの自治体は「事務事業評価シート」という形で、個々の事業の目的・コスト・成果・今後の方向性を公表しています。ただし多くの場合PDFで、しかも数百ページに及ぶため、住民が実際に読んで判断材料にするのは現実的ではありません。

このツールは、その構造化されていないPDFを、住民が1事業ずつ「続行・廃止・見直し」を判断できる形に変換します。ただし、評価結果を自治体の予算査定などの意思決定プロセスに直接組み込む仕組みまでは持っていません。あくまで「行政のデータを住民が読める形にし、意見表明の場を作る」ところまでが本ツールの役割です。

## 公開URL
https://onuma-spec.github.io/jimujigyou-hyoka/

ツールの解説は[about.html](https://onuma-spec.github.io/jimujigyou-hyoka/about.html)を参照してください。導入自治体の一覧は公開URLのトップページでご覧いただけます。

## 使い方
1. **自治体選択画面**：都道府県→市区町村を選び、「このツールを開く」を押す
2. **マップ画面**：施策（行政サービスの分野）を選ぶ。法定義務の有無で事務事業を絞り込むこともできる
3. **施策画面**：事務事業の一覧から、評価したいものにチェックを入れて「選択した事務事業を評価する」を押す
4. **評価画面**：事務事業ごとに「続行」「廃止」「見直し」のどれかを選ぶ。「評価シートを確認」から元の評価シート（PDF）を開ける
5. **サマリー・投票画面**：自分の評価とみんなの評価を一覧で確認し、「投票する」で自分の評価を共有する。印刷・CSV保存もできる

評価画面では、自分用のメモを書いたり、ほかの人の投票結果やコメントを見たりできます。どの項目を表示するかは、自分で切り替えられます。

## データの扱い

- **評価・メモ**：ブラウザ（localStorage）にだけ保存され、外部には送信されません
- **投票**：「投票する」を押したときだけ、自治体ID・事業番号・評価結果（続行/廃止/見直し）・送信日時を、集計用の Google スプレッドシート（Google Apps Script 経由）に送信します。個人情報は収集しません
- **コメント**：投稿したコメントは匿名でみんなに公開されます。電話番号・メールアドレス・URL・氏名を明示する表現は送信前に自動でチェックしますが、完全ではありません。不適切なコメントは通報でき、通報が一定数に達すると非表示になります

## 自分の自治体でも作ってみたい方へ

このツールをベースに、任意の自治体版を自分で作れる制作キットを公開しています。→ [jimujigyou-hyoka-starter-kit](https://github.com/onuma-spec/jimujigyou-hyoka-starter-kit)

評価シートPDFから、事業ごとに👍👎で投票・コメントできるツールを手軽に作れる別ツールもあります。→ [事務事業評価 事業一覧ツール](https://onuma-spec.github.io/jimujigyou-hyoka-list/)

## 作成について

本ツールは、自治体が公表した一次資料に基づき、Claude（AI）を用いて作成しています。各自治体の公式なツールではありません。
